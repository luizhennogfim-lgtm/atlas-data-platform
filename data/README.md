# Data

Everything here is **synthetic**: a fictional e-commerce company, fake names, `example.com` emails.
No real person or company is represented.

`sample/` holds four CSV files generated by `python -m ingestion.generate_data` (seed 42, deterministic):

| File | Columns |
|---|---|
| `customers.csv` | customer_id, email, full_name, country, signup_date |
| `products.csv` | product_id, product_name, category, unit_price |
| `orders.csv` | order_id, customer_id, order_date, status (completed / cancelled / returned) |
| `order_items.csv` | order_item_id, order_id, product_id, quantity, unit_price |

The files contain a **small, deliberate set of defects** (duplicates, negative or non-numeric prices, impossible
dates, orphan keys, invalid status) so the quality layer has real work to do. They are listed in
`ingestion/generate_data.py`. Any number computed from this data is a demonstration, not a business result.
